# 数据与分析报告作业 · 要求

## 背景

公司 2024 年度的考勤与绩效数据已经整理好（数据文件由课程单独提供，不随本作业提交）。你要基于这份数据写一份简短的数据分析报告，回答一个问题：**加班时长与个人产出之间是什么关系**。

## 要求

1. 报告正文 500–800 字（不含标题、表格与参考文献）。
2. 报告中的每个结论都必须有数据或引用支持。
3. 正文中引用的数字必须与表格中的数据一致。
4. 至少包含一张表格，按加班时长分组呈现各组的平均产出。
5. 说明数据的样本量（参与统计的员工人数或记录条数）。
6. 在结论部分给出 1–2 条管理建议，且建议必须由前面的数据支持。

## 提交方式

只提交一份 Markdown 报告。文中所有数字都要能在报告内部对上；不要引入没有出处的数字。

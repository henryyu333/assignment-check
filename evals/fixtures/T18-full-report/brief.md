# ECO110 — Mini Policy Memo

## Task

Write a short memo comparing two transport options for a small university campus.

Your submission must:

1. State the decision question clearly.
2. Explain **Option A: electric shuttle buses**.
3. Explain **Option B: expanded bike-share**.
4. **Compare A and B on both cost and implementation time.**
5. Give one recommendation and justify it using the comparison.

No rubric or numeric score is provided.

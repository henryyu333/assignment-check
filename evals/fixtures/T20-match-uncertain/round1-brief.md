# 《传播学概论》期末小论文作业要求

**提交时间：** 第 16 周周五 23:59
**提交格式：** Word 文档（.docx），宋体小四，1.5 倍行距

**选题范围：** 自选一个与「数字媒介与社会」相关的议题，写一篇小论文。

**要求：**

1. **字数。** 全文 800–1000 字，不含标题与参考文献。
2. **证据。** 论证必须有证据支持：每一个核心论断都要有数据、文献或具体案例作为依据，不允许只给出断言而不给依据。
3. **论点与结构。** 需有明确的中心论点，并分节展开；正文至少包含三个小节。
4. **文献。** 至少引用 3 篇学术文献，并在正文中标注出处。
5. **引用格式。** 正文标注与文末参考文献需全文统一，统一采用 GB/T 7714 顺序编码制（正文用 [1]、[2] 等形式标注）。

**说明：** 引用他人观点而未标注来源，按学术不端处理。

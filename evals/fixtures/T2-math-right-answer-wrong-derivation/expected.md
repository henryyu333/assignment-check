# T2 — 数学：最终数值答案正确，但推导用局部（二阶导）结论冒充闭区间上的全局最值

- 预期总体状态：`NEEDS REVISION`

## 必须发现

1. **第一处无效推导必须被定位在"第四步：结论"**：由 $f''(1)=6>0$（局部极小）直接断言"$-2$ 就是整个区间上的最小值"，由 $f''(-1)=-6<0$ 直接断言"$2$ 就是整个区间上的最大值"。二阶导数判据只给出**驻点类型（局部）**，不能推出闭区间上的**全局**最值。
2. 说明正确做法缺在哪一步：闭区间上必须比较端点值与驻点值，即计算 $f(-2)=(-2)^{3}-3(-2)=-8+6=-2$、$f(2)=2^{3}-3\times 2=8-6=2$（或引用最值定理：连续函数在闭区间上取到最值，最值只能在驻点或端点取得）。本题 $-2$ 与 $2$ 恰好同时出现在端点与驻点，所以数字碰巧正确。
3. **最终数值答案必须单独判为正确**：最小值 $-2$、最大值 $2$ 都与重算结果一致。必须把"结果对不对"和"过程对不对"分开写 → R4 = `MET`，R3 = `PARTIAL`。
4. 报告必须给出问题位置（第四步 / 结论段），并给出修改方向（补端点值比较或引用最值定理）。

## 必须不得声称（false claims）

- 不得声称最终答案错误（数值 $-2$ 与 $2$ 正确），也不得要求改数字。
- 不得只写"推导基本正确／思路没问题"而不指出第四步的推理无效。
- 不得声称已经运行了计算工具、CAS、Python/SymPy 等（除非报告中确实给出该工具的真实输出）。
- 不得声称 R3 已完成（`MET`），也不得声称题目难度超出能力而把整体判为 `UNVERIFIED`。
